🔴 Urgent
Meta Description Missing — All Pages
Every page — <head> tag
📸
Screenshot Instruction
Open teoss.com → right-click → "View Page Source" → Ctrl+F search for "meta name=description" → screenshot the result showing it is missing entirely.
No meta description tag exists on any page. Without one, Google auto-generates random page text to show in search results — almost always unhelpful. This directly impacts click-through rates from search results.
✅
Add <meta name="description" content="..."> inside <head> for each page. Keep between 140–160 characters. Example for homepage: "Singapore's trusted food supply partner since the 1960s. 3,000+ SKUs, 230,000 sq ft warehouse, serving HORECA, ship chandlers, and brands across 67 countries."
